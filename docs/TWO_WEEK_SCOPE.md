# TWO_WEEK_SCOPE

## 项目定位

基于 ROS2 的多场景四旋翼动力学、控制、三维感知、路径规划、扰动评测与重庆山地城市视觉回放平台。

## 本轮不做

- Unreal Engine；
- PX4 全栈迁移；
- 完整 SLAM；
- 强化学习；
- 大模型在线决策；
- 研究级 CFD；
- 复杂多机编队；
- 真实硬件部署。

## 14 天计划

| 天数 | 任务 |
|---|---|
| 1 | 要求追踪、范围冻结、drone_world |
| 2 | 场景库、PointCloud2、随机地图 |
| 3–4 | 3D voxel 与 3D A* |
| 5 | 飞越/钻越、不可达处理 |
| 6 | 路径平滑与约束对比 |
| 7 | 有限视野局部感知 |
| 8 | 动态障碍与在线重规划 |
| 9 | 风、外力、IMU 噪声 |
| 10 | 圆/八字轨迹、双无人机 |
| 11 | PySide6 地面站 |
| 12 | CesiumJS 重庆视觉回放 |
| 13 | 测试、回归、失败案例、仓库比较 |
| 14 | README、AI 说明、报告、视频、GitHub |

第 12 天后禁止新增核心功能。
